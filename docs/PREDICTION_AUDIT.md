# 预测评估与受控改进

## 当前模型与分数

当前线上判断由五个确定性判断器和一个确定性集成构成；没有接入大模型预测，也没有训练基础模型。

| 名称 | 类型 | 当前输出的含义 |
| --- | --- | --- |
| `cycle_trend` | 规则模型 | 多周期趋势与相对强度规则分 |
| `leader_sentiment` | 规则/因子模型 | 龙头、市场广度、情绪和流动性因子分 |
| `chan_structure` | 确定性近似规则模型 | 结构与背驰规则分，不代表唯一缠论定义 |
| `multi_factor` | 规则因子模型 | 趋势、动量、量价、估值等因子分 |
| `market_regime` | 规则模型 | 市场状态规则分 |
| `advisor_rules_ensemble` | 规则加权混合模型 | 集成方向分及各规则的一致程度 |

旧字段 `confidence` 保留风控后数值以兼容旧客户端；`model_confidence` 单独保存风控前的规则一致程度。桌面模型独立判断使用 `model_confidence`，称“规则符合分”，附带 `confidence_type=rule_conformance_score`。它表示输入覆盖程度与规则信号一致程度，**不是预测成功概率**。正式台账中的原始概率、校准概率保持 `null`。单策略的 `confidence` 是输入覆盖度，不是概率。

`market_prediction` 只使用模型原始方向分和规则一致度，不读取持仓、成本、股数、现金、仓位或账户回撤；账户约束仅影响操作建议。旧服务未提供独立规则分时显示未知，不用风控后字段冒充独立输出。现有模型没有独立验证的未来收益幅度模型，因此 `expected_return` 和 `return_interval` 保持 `null`，界面显示“尚未验证”。5日收益标签用于事后评价，不是对未来收益幅度的精确预测。

## 预测目标

每条联网自动分析在生成时固定写入 `forward_positive_return_5_sessions_v1`：预测信息截止日之后第一个可用交易日开盘买入参考价，到其后第五个可用交易日收盘参考价，标的前复权收益是否大于零；同期沪深300方向作为对照。这个标签评价市场事件方向，不是买入建议的成功概率，也不是可执行策略收益。

到期结算只使用信息截止日期之后的日线，并要求沪深300同期基准齐全。未取得完整5个已结束交易日、行情状态不新鲜或基准缺失时保留待结算并记录原因。当前历史价格接口不能可靠还原所有停牌、除权除息和历史成分变更；结算是市场事件评价，不模拟成交。

## 台账、账户约束与数据位置

正式自动分析写入追加式 JSONL 事件日志，包含哈希链、预测ID、重复查询关联、时间截止、模型版本、输入快照与哈希、来源、质量状态、规则输出、固定目标、账户持仓上下文及风险结果。完全相同的模型版本、信息截止、输入和风险上下文不会重复计作新预测。实验记录使用单独的 `experiment` 模式。

修正、到期结算、失败尝试、实际账户成交关联、候选版本与审核均追加新事件；不改写原预测。该哈希链用于发现文件中途篡改，不是带第三方签名的防伪存证。

桌面版的台账位于工具目录下的 `UserData\prediction_audit.jsonl`（可用环境变量 `XIAO_A_AUDIT_FILE` 指定）。开发运行默认位于 `%LOCALAPPDATA%\XiaoAAdvisor\prediction_audit.jsonl`。原有 `portfolio.json` 不迁移、不重写。

系统只允许多头账户：没有持仓时负面观点显示为“不买入”；有持仓时卖出建议最多不超过系统可核实的T+1可卖数量。账户没有逐笔持仓批次时，具体卖出数量标为未知，不猜。现有账户交易接口拒绝卖出当日买入的股份。没有单笔风险预算或止损距离时不虚构买入股数。没有借券、裸空、负持仓或杠杆路径。

## 评分与校准

“评估”页面显示正式记录数、待结算数、到期方向统计、失败分析次数、数据状态、哈希链完整性和候选版本。统计只使用已结算正式记录；实验记录与重复查询不进入正式样本。报告按模型、目标期限和子模型分组提供事件率、方向命中率、Precision、Recall、ROC-AUC；样本少或类别单一时显示证据不足。多个预测共享日期或期限时并非独立样本，当前区间只作描述。

校准报告采用按日期排序的开发/校准/最终测试三段（50%/20%/30%），开发与校准段的标签须在下一段边界前结束，跨界样本被剔除；使用 Platt 逻辑映射，只在校准段拟合，在最终测试段计算校准 Brier、Log Loss 和可靠性分档。为了诊断比较，另报告固定线性规则分映射 `(score + 1) / 2` 的 Brier/Log Loss；该映射不是模型原始概率，必须与校准后结果区分。没有足够时间段或类别时不拟合。即使报告有可计算结果，当前仍将 `calibrated_probability_available_for_production=false`；显示结果不等于校准可靠，更不会改变实盘决策。

现阶段没有模型概率，所以 Brier/Log Loss 的生产台账统计会保持空值。规则符合分没有自动转成概率。收益、最大回撤、换手和风险调整收益要求另行预注册仓位、交易触发、费用及成交方案；不能从市场事件命中率推导。报告明确显示策略价值和账户风控价值尚未验证。

## 受控改进

候选记录要求版本、理由、允许的策略配置变更和预先登记的评价方案。候选只能处于影子/审核状态，提交时固定 `active=false`；接口拒绝试图变更硬风控、空头、杠杆、账户上限或实盘权限的候选。审核通过需明确时间外验证与前瞻影子观察状态，并记录审核人和原因；即使通过也只是“待人工发布”，不会自动替换生产版本。拒绝与回滚都保留新事件。常规亏损不会触发自动改规则或训练。

当前客户端仅提供候选版本登记与审核轨迹展示；**候选代码自动并行运行、统一策略成交模拟和一键发布/回滚尚未接入**。因此登记候选不会生成可信的候选预测，也不会改变当前模型。基础大模型权重训练、收益区间及共形预测不在本次实现范围。

## 使用

1. 在桌面端打开“预测评估”。联网自动个股分析会产生正式记录；离线缓存不新增预测。
2. 到期后点“结算已到期预测”。系统只在可取得完整前复权行情及同期基准时结算，其余会保留失败原因。
3. 对比市场方向统计、时间隔离校准和数据完整性；不要把方向命中率当成收益。
4. 查看历史记录的风险上下文和卖出数量状态。若 T+1 股数未知，仍需先核对券商。
5. 候选改动不得自动生效。候选阶段目前只保存审计信息，不执行替代策略。

## 复核提醒（桌面 1.0.3）

程序运行时启动检查，此后每5分钟检查已有台账；“评估”页可手动检查。提醒只参考已结算记录，不自动联网结算，也不更改模型、账户硬风控、权重或交易权限。关闭程序后不运行通知任务。

- 哈希链异常直接提示“需复核”，暂停评分，不向损坏台账追加事件。
- 最近30个自然日内，最近3个有分析记录的日期，每日至少一半的标的/日期单位存在数据陈旧、缺失或分析失败，且累计至少5单位，提示先查数据；同一股票同一天重复失败不会扩大样本。
- 尚未到期不报警；待结算记录在3个不同检查日持续缺少可靠数据才提示结算质量复核。
- 表现监测按模型、完整版本、目标和期限分组，使用原始方向分，与账户情况无关。同一日同一股票取事先规定的首条正式预测，同日多股按日期组汇总；跨日期预测窗口重叠时剔除。至少8个历史参考组和两个连续各8组观察窗口才启动方向偏差监测。基准方向只用两个观察窗口之前的历史事件率确定；两窗口的模型相对基准方向命中率差异，经日期组重采样后的95%区间上界均低于-5个百分点才发起人工复核。
- 上述24组等数量仅是版本化监测规则，不证明模型准确、失效或应当修改。日期分组、剔除与重采样仍无法消除金融时序相关性；反复监测存在误报可能。
- 当前生产模型没有经过验证的概率，所以不发出“长期过度自信”的概率报警；绝不把规则符合分当成概率。

活动提醒在窗口右上角显示入口；新提醒在程序内提示一次，重复轮询不会反复弹出。评估页显示原因和证据，可点击“复制复核报告”粘贴到聊天中供人工核查。“已知晓”只保存确认，不表示已修复或批准升级。触发、确认和条件消退均追加审计事件，同一持续问题保留一个提醒ID。

本轮测试使用明确标记的合成数据，只验证监测与账本代码正确性，不代表当前真实模型存在上述偏差。

本功能不接入自动下单、不承诺盈利，也不会因为看涨分数高而绕过账户硬风控。
# 1.0.8 结算数据兼容修复

腾讯指数历史行情使用 `day` 字段，即使请求参数为 `qfq`。适配器允许已识别的指数使用该字段，沪深300使用原始指数点位；个股仍必须使用 `qfqday`，不得静默降为未复权价格。

同日失败后可以再次点击到期结算，方便数据源恢复后重试。每次尝试仍追加审计事件，不覆盖原预测或历史失败原因。界面不再把旧失败原因附在已经结算成功的记录后面。没有5个完整后续交易日、标的/基准数据不可用或同期日期缺失时仍保持待结算；当前未结束交易日不计入窗口。

新增测试使用明确的合成行情，仅验证字段解析、价格口径、同日重试与到期隔离，不构成真实预测准确率或收益证据。
