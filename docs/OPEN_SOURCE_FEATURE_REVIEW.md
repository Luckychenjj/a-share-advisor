# 五个开源项目拆解与小A顾问移植记录

本文按小A顾问当前代码核对，区分“已有能力”“可借鉴能力”和“本次落地”，不直接复制上游实现。

| 项目 | 可用能力 | 小A顾问现状 | 结论 |
|---|---|---|---|
| AKShare | 聚合A股、指数、财务等公开数据接口 | 已有腾讯、东方财富、财联社等分层数据源和失败回退 | 暂不整体引入：会增加较多依赖，且上游数据页面/接口变化需要持续维护；保留逐项评估其独有数据接口的空间 |
| Tushare | 结构化行情、财务和选股数据 | 已有行情、财务信息和全市场筛选 | 暂不默认接入：Pro需用户Token，数据权限按账号开通；未来可以做可选Provider，不能作为默认免费数据源 |
| QuantStats | 收益、波动、回撤及组合复盘 | 原来只显示当日盈亏，缺少跨日权益曲线和账户回撤 | 本次移植其“基于权益序列做账户复盘”的思路，以本地轻量计算新增收益/回撤指标，不增加第三方依赖 |
| RQAlpha | 事件驱动回测、交易规则和风险约束 | 已有A股回测器：次日开盘、T+1、整手、涨跌停、费用与滑点 | 保留现有实现；可继续增强历史数据与报告。RQAlpha许可对商业用途有限制，不直接复制代码或作为可分发依赖 |
| Lightweight Charts | 交互K线、十字线和标注 | Flutter端已有日K交互、缩放/拖动/十字线及分时图 | 暂不替换图表栈；值得借鉴的是交易点与关键价格标注，需单独评估Flutter实现与维护成本 |

## 本次实现

- 账户页新增“收益与风险复盘”：累计收益、最大回撤、年化波动率、夏普比率、正收益区间占比及有效记录数。
- 账户权益在本机保存；只有持仓行情完整且状态为新鲜、所有持仓报价属于同一交易日时才生成快照。纯现金账户也可记录。
- 波动率和夏普比率至少需要20个观测区间；少于此数量时明确显示暂无足够样本。
- 这是用户读取账户时点的本地估值，不是券商结算单；更新前的数据不会凭空补造。行情不完整或陈旧时跳过该日记录。
- 不新增AKShare、Tushare Pro、QuantStats、RQAlpha或Lightweight Charts依赖，也不将账户或交易记录发送到外部服务。

## 许可与使用边界

- [AKShare](https://github.com/akfamily/akshare)声明MIT许可；该项目要求Python 3.11及以上。集成前还需评估它带来的依赖体积和数据接口稳定性。
- [Tushare Pro官方说明](https://tushare.pro/document/1?doc_id=40)要求注册并取得Token；具体接口仍受用户权限约束。
- [QuantStats](https://github.com/ranaroussi/quantstats)使用Apache-2.0。本次只独立实现必要统计，没有复制其代码。
- [RQAlpha许可](https://github.com/ricequant/rqalpha/blob/master/LICENSE)规定商业用途需取得授权；本项目后续若面向其他用户分发，不应未经授权引用或借鉴其实现代码。
- [Lightweight Charts](https://github.com/tradingview/lightweight-charts)使用Apache-2.0；替换现有图表时需同时落实相应版权/NOTICE要求并评估归属展示。
